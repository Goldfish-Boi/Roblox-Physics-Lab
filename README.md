# [Roblox Physics Lab](https://www.roblox.com/games/99414963233126/Roblox-Physics-Lab)

Roblox Physics Lab is a collection of physics simulations inspired by PHET iteractive simulations. The simulations are made from scratch and do not use Roblox's built-in physics engine.

Instructions to run:
1. Create a Roblox account if you do not have one currently
2. Open the experience page, the link is embedded into the readme title
3. Click the play button while signed into your Roblox account

Instuctions to use source code:
1. Install the latest version of Roblox Studio
2. Download and open the .RBXL place file

Roblox Physics Lab currently contains the following simulations:
- Medium Refraction - See how light behaves when moving through transparent mediums of different refractive indexes. Drag the blue part of the laser to move it and the magenta part to rotate it. Drag the medium to change its height. Add as many lasers as you like!
- Bouncy Ball - See how a ball falling loses its energy when it hits the surface. Drag the ball to move it around. Drag the surface to change its height.
- Obby - Not a physics simulation at all, a bonus game to play added just for fun.
